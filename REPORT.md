# Architecture

One async Python process controls a separate Flask application through Playwright.
Pydantic contracts separate discovery, compilation, guarded execution, replay,
ownership and evidence. A genuine LLM selects actions from fresh masked screenshots
and bounded visible controls, without scripted navigation or hidden application
state. The task contract supplies inputs, outputs and independent acceptance
conditions; arbitrary goal synthesis is outside scope. Success cannot rest on a
model completion declaration or operator completion signal alone.

Discovery and replay share GuardedExecutor and Surface. The fixture includes an
iframe, tables, an unlabelled field and no test IDs. Genuine discovery made eight
model decisions and compiled nine steps for member 12345. Unchanged-artifact replay
for 06789 returns 987654 cents/USD. Evidence distinguishes real model/human
executions from tests.

# Artifact schema

Schema 1.0 declares capability ID/semantic version, application family/version,
typed inputs/outputs, ordered stable step IDs, locator candidates/rationale,
pre/postconditions, deterministic extraction parsers,
terminal predicates, business outcomes and provenance. Member IDs remain strings;
money uses integer minor units. Bindings distinguish literals, caller inputs and
earlier extractions. Invalid/forward references, unsupported operations and versions
are rejected; replay revalidates existing model instances.

Grounding uses exact observed-value provenance rather than substring replacement.
Compilation rejects weak structural targets, concrete identifiers and human-assisted
traces. Ephemeral IDs and raw model transcripts are excluded. An optional runtime
sidecar binds reviewed exception predicates and bounded recoveries to exact
capability/application versions, preserving original artifact bytes. Intervention
state stays in the live run.

# Determinism & error handling

Replay imports no model provider; its CLI removes supported provider keys and blocks
non-loopback Python connections. Targets combine frame-scoped semantic names,
identifying rows and limited caption-relative structure. Missing candidates permit
fallback; ambiguity, conflicting candidates or identity/effect mismatch stop.
Coordinate discovery uses exact DOM hit-testing and grounding, never replay
coordinates. Independent checkpoints verify outputs and member identity.

Success returns outputs. BusinessOutcome represents missing member/account,
validation rejection or permission denial. Failure includes capability/version, step,
code/category, expected/observed state, evidence, recovery history, uncertainty and
escalation suitability. Invalid invocations fail before actions. Unknown
confirmations, expiry and persistent errors stop; unknown native dialogs are
dismissed during automation and latched.

Recovery permits one harmless continuation, two inspected GET-link retries or three
0.25-second waits, within six shared attempts and finite run/per-rule deadlines.
It never resubmits forms or repeats uncertain original actions. Only a known
false-to-true nonempty checkpoint reconciles completion; already-true/unknown
baselines, missing extraction data or safety latches cannot. Error disappearance
does not establish success. Diagnostics include masked screenshots or an explicit
unavailable signal.

# Heterogeneity & multi-tenant

Surface exposes observations, opaque resolved handles, inspected effects, primitives
and navigation/safety state; replay has no raw Playwright locators. Desktop support
requires accessibility/native target variants and an adapter. Web table semantics
cannot simply become desktop locators.

Compatibility is separate from origin; relative entry paths and exact-origin policy
allow instance reuse. Proposed tenant reuse combines immutable vendor/version bases
with reviewed data-only branding/target overrides. Revalidate the materialized
artifact, preserve identity/safety predicates and record base/override digests.
Version/application/checkpoint mismatches require review or versioned rediscovery.
Separate contexts and credential stores would isolate tenants. Overrides and tenant
infrastructure remain design only; demonstrated reuse varies members/origins.

# Escalation & handoff

A shared discovery/replay coordinator recognizes one reviewed read-only challenge.
Its nonterminal request identifies run/capability/goal, step, original session/page,
sanitized diagnosis/evidence, uncertainty, resume predicates, status and ownership
generation. Policy denials cannot become override requests.

The lock settles guarded operations before AUTOMATION -> PAUSED -> HUMAN.
Takeover retains the same live session rather than launching a replacement browser.
The original browser/context/page and coroutine retain cursor, bindings, outputs
and recovery history. Generation checks reject stale queued actions. Console input
does not block browser events; a bounded operator deadline pauses the automation
deadline. Capture records click/change/submit tags and frame navigation without values.

RESUMING reconciliation checks original session/context/page, origin/application,
clear latches, expected member, absent blocker and interrupted checkpoint under
the lock. Two observations must agree. Wrong member/view, unresolved state, closure,
stale generation or policy signals stop. Unknown completion is never blindly retried.
Execution resumes at the suspended point; cancellation/unresolved/timeout return
specific Failures. Assisted discovery cannot compile unattended steps. Evidence
includes real human resolution/cancellation; discovery handoff is tested with a
scripted provider.

# Safety

Origin/read-route/GET/action allowlists cover navigation, clicks, forms, keyboard
submission and recovery, using inspected effects rather than model risk labels.
Financial mutation stays blocked during human control; the fixture independently
refuses it. Interception fetches one permitted response without following redirects
and rejects redirects before fulfillment. Native/network safety signals remain
latched across handoff. Protections assume reviewed routes, not hostile-page isolation.

Only fictional records are used. Logs exclude raw DOM, cookies, storage, keystrokes,
SDK error bodies and credentials. Screenshots mask fields; sanitization is
fixture-specific. Manual capture can lose navigation events and is not forensic
recording. Public inventory excludes private context, environments, caches and
machine-specific metadata; historical records remain unchanged.

# Cuts

Scope is one synthetic workflow with strict USD parsing and DOM-backed targeting
at 1100x800. Canvas-only, inaccessible cross-origin and desktop surfaces are
unsupported. Handoff supports reviewed acknowledgement, not arbitrary repair/login.
Continuation requires the live process. Operators must stop physical input during
reconciliation: detected changes fail closed, but input isolation and atomic UI-state
guarantees are absent. One discovery proves feasibility, not cross-application reliability.

Queues, databases, remote consoles, general branching, catalogs, code generation
and model-assisted replay repair are excluded. Broader fixtures, repeated discoveries
and accessibility targets need evaluation; durable continuation and secure operator
isolation require explicit persistence/security design.
